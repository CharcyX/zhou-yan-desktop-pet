# Zhou Yan Desktop Pets

本仓库保留粥盐与周延两只不同角色，各自拥有独立源码、Codex v2 图集和 macOS、Windows 下载包。

## 粥盐

- `zhou-yan/`：粥盐的 Codex v2 图集、macOS 和 Windows 源码。
- `releases/`：粥盐的 macOS 与 Windows 安装包。

## 周延

- `zhou-yan-周延/zhou-yan/`：周延原版的 Codex v2 图集、macOS 和 Windows 源码。
- `zhou-yan-周延/releases/`：周延原版的 macOS 与 Windows 安装包。
- `zhou-yan-周延/README.md`：周延原版的使用说明。
