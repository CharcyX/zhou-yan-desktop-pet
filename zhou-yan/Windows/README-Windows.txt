粥盐 Windows 独立桌宠

启动：双击 start-zhou-yan.bat。

要求：Windows 10/11，Python 3（安装时勾选 Add Python to PATH）。使用 Python 自带 Tk，不需要额外 pip 包。

透明背景：Windows 专用 RGB 图集使用纯色 #D12AFF 色键与 alpha>=128 硬边蒙版；不会把半透明边缘和洋红色混合，避免紫/洋红描边。不要改回 macOS RGBA 图集。

交互与 README 相同：鼠标悬停播放角色专属动作，第 3 次悬停结束后触发负面反应；外圈 60 px 播放 16 向注视；左键拖动按方向跑步，累计超过 7 秒后触发负面反应。右键或 Esc 退出。
